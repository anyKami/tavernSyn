# 0.2.4 审查问题核对与修复

核对日期：2026-10-26。基准为 `31728933`（0.2.4），修复包含在 0.2.5 中，与增量同步优化一同发布。此次没有部署用户酒馆、手机或线上 VPS，也没有进行安全审计。

## 核对结果

| 报告项目 | 核对结论 | 当前处理 |
| --- | --- | --- |

另外发现 VPS 更新器仍用 `0.2.2` 常量校验新分发器，这会拒绝后续版本。现从同一安装源的 `package.json` 读取版本，并在运行探针时核对；隔离测试也复制新增的空间报告工具。

## 文件属性与兼容

载荷仍使用 format 1 清单及协议 1。执行信息放在 `environment.json.executables`，该文件本身受清单 SHA-256 校验；不依赖 rsync 的权限传输，也不放开 VPS 的 `perms/chmod` 限制。

只恢复文件拥有者执行位：普通文件 0600，可执行文件 0700，目录 0700。不会迁移属主、组/其他用户权限或特殊位。POSIX 来源按实际执行位记录；Windows 来源使用 Git 索引模式和本机 `file-attributes.json`。Git 索引声明的模式更新会覆盖以前记录的同一路径属性。

本机属性文件跟配置、共享根一同进入替换与回滚日志，日志升级为 format 2，仍支持恢复旧 format 1 日志。基准摘要包括执行信息，权限变化不会被无变化快速路径忽略。

旧快照缺少执行元数据时，可从 Git 索引恢复受跟踪脚本的执行模式；已经丢失的非 Git 文件执行位无法凭空推断。需要从仍保留正确属性的设备重新推送。

## 已提交结果与收尾

- 推送以经过认证的 VPS 发布回执为提交事实；拉取在本机替换、健康检查和应用日志提交后记录事实。
- `jobs/<id>/outcome.json` 在移动冻结载荷之前写入；拉取的提交日志也包含完成信息。缓存、历史、基准或最终状态写入失败显示 `SUCCEEDED` 和 `maintenancePending`，不显示普通上传失败，也不提供已失效的继续上传按钮。
- 状态写队列可以在单次写入失败后恢复。历史读取错误不会令整个状态接口失败；任务锁释放失败也不会让已完成任务的 Promise 变成未处理拒绝。
- 存在待整理结果时，先处理结果核对再开始下一任务或切换连接，避免覆盖尚需核对的缓存和绑定。
- 面板的“核对同步结果”只补做本机整理，不重新应用、上传或重启。已有本机提交回执时可离线整理。缺少发布回执时，只在认证的 VPS 当前代次 UUID 与原快照 SHA-256 同时匹配时补认发布；另一个 UUID 即便摘要相同，也不会被认作该任务。
- VPS 指针已发布后的任务记录或回收失败，返回已发布事实及维护警告；指针替换后的目录同步错误也核对实际指针后保留警告，不伪称未发布。

命令行核对同一个任务：

```sh
node bin/reconcile.mjs --state "设备控制目录" --job 任务UUID
```

旧进程遗留锁时仍须先按恢复说明确认进程退出，工具不会接管活进程。若磁盘完全不可写，不能保证任何新记录持久化；保留冻结载荷并报告实时结果，恢复写入后再核对。文件系统断电持久性仍不等于进程故障测试。

## 原生资源与聊天核对

常见动态 script 的 src 属性、setAttribute、DOM 插入、Worker、SharedWorker 和 ServiceWorker 注册会为本机插件 API URL 绑定当前代次。资源通道要求 GET/HEAD、同源浏览器资源上下文及当前 URL 代次；嵌套模块通过带代次 URL 重定向延续核对，证明参数在交给插件处理器前移除。现有 Cookie、管理员和 CSRF 行为保留。

这不是所有第三方加载方式的统一适配层。原始 HTML 解析器创建的 API 脚本、document.write、独立 iframe、blob Worker 等未经过上述入口的加载方式仍需插件提供带代次 URL或专项适配。测试覆盖合成插件的实际 HTTP 路由和浏览器入口 VM，不宣称所有真实插件或浏览器 Worker 已验收。

聊天核对逐行解析 JSONL，保持原来的消息/元数据规范化摘要；同一次读取计算原始文件摘要，前后校验文件状态，避免读到写入中的聊天。内存受单条消息大小影响，不再同时保留整文件文本、行数组和所有消息对象。测试用超过 64 MiB 的聊天在 32 MiB Node 堆限制下完成核对；前端已有聊天内存与其他全量扫描未因此消失。

## VPS 只读空间报告

在源码目录运行：

```sh
python3 vps/storage-status.py --root /srv/tavernsyn
```

报告磁盘总量与空闲量、incoming/generations 各代次逻辑字节、保留任务 UUID，空间低于 10% 或 32 MiB 时提示。统计是读取时的快照，逻辑字节不代表 reflink 后的实际独占空间。它不删除内容，也不修改状态或加写锁。

不再需要的已绑定任务，仍可通过 `bin/remote-job.mjs --state "设备控制目录" --job 任务UUID --action abort` 明确中止。已发布代次不能通过中止撤销，孤立目录不自动猜测归属或按时间删除。
