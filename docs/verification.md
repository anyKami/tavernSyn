# 第一阶段验证结果与最终验收计划

核查日期：2026-10-23。研究版本：SillyTavern 1.19.0 / release / `06bde939fb1e9c4c8d8641d810f0a916b5bce127`。

## 本阶段实际结果

**Windows 隔离真实 release 的生命周期探针通过。跨设备同步产品尚未实现，端到端验收尚未通过。**

探针使用 git archive 副本、自己的新用户数据和随机端口 62141；没有复制真实聊天或密钥，没有在用户正式安装中启用服务端插件或修改配置。源安装的依赖通过 junction 复用，没有联网安装。两个测试实例均完成退出钩子并以 0 退出；测试端口已复核无监听。

可发布的[实际结果 JSON](test-results/windows-restart-2026-10-23.json)、[完整结果解释](research/restart-probe-results.md)和 [probe 源码](../probes/restart-probe.mjs)均在本项目中。`.tmp` 下副本和日志是忽略的测试产物，不是需要发布的依赖。

| 验证项目 | 状态 | 实际证据/边界 |
| --- | --- | --- |
| 官方 UI 扩展入口与保存接口 | 文档/源码已核对 | [前端调查](research/frontend.md)列出准确行号；未用真实浏览器点击 |
| 原生 Server Plugin info/init/exit | 隔离实测通过 | 测试插件由真实 ST loader 加载并注册路由 |

| IPC 实例 nonce | 隔离实测通过 | 错误 nonce 被拒绝 |
| 未托管实例拒绝分支 | 模拟分支实测通过 | 返回 409；没有验证真实手工实例接管，也不计划按端口/PID接管 |

“通过”仅对应实际列出的检查。探针中的 response.finish/close 计数不能直接作为生产严格写入屏障：断连可能先于业务结束，第三方插件也可能在响应后继续写入。它没有实现实际同步、等待页、epoch屏障、保存回执、恢复journal或完整安装器。

## 复现

从项目根运行：

```powershell
npm run verify:restart -- "D:\SillyTavern"
```

也可直接运行 `node probes/restart-probe.mjs <已安装ST目录>`。不需要在本项目 npm install；依赖由已安装的相同固定 ST 提供。源commit不匹配直接失败。需要 Node、Git、tar 及允许本机loopback；每次创建新副本/随机端口，无需启动正式8000实例。

探针只用于可行性研究，不能作为日常启动器；复现尚未覆盖的断连/异常插件可能暴露退出局限，应只在模拟副本中运行。

## 后续验收矩阵

以下全部为**待实现/待测试**，不能从Windows探针成功推定通过。先模拟数据与临时远端目录，再在实际Windows、Android Termux和独立VPS存储根验证。

| 验收项 | 必须满足的可观察结果 |
| --- | --- |
| Windows推送→Android拉取 | 固定代次、清单一致；拉取应用及对应新实例健康后才成功 |
| Android推送→Windows拉取 | 同上，Windows路径/文件锁不被忽略 |
| 聊天/群聊/角色/世界书/预设 | 内容及metadata/integrity一致；酒馆能加载，非仅文件计数一致 |
| 图片/附件/人格/CSS | 全部原始资源可访问，无失效引用；设备当前布局按保留表处理 |
| API连接及密钥 | 使用模拟秘密值核对；真实测试日志/报告不包含秘密 |
| 保存确认 | 防抖重排队、HTTP200错误body、写盘失败、超时/切聊天均不误报ACK |
| 未提交编辑器/后台写入 | 不能确认的角色/预设/世界书编辑或插件明确阻断严格流程 |
| 浏览器按钮和重连 | 两按钮正常工作；等待页文档ACK、刷新/CSRF恢复、任务结果与持久状态一致 |
| 旧页面重放 | BFCache/返回历史/多个hostname/多标签页/休眠页不能覆盖已拉取数据；epoch屏障必须实测 |
| Windows拉取后重启 | 只操作已持有的实例，保存/排空/退出/应用/新健康顺序可证明 |
| Termux拉取后重启 | 同上，使用真实手机浏览器；Android后台回收后能从journal恢复 |
| 未受控与失败降级 | 已下载数据保留PENDING_APPLY；手动关闭后受控入口应用；未应用不报成功 |
| Git前端扩展 | 从目标自己的Git工作区恢复精确SHA、启用状态及可移植本地修改；仍保留后续更新入口 |
| CDN脚本与浏览器限制 | 落盘配置正确恢复；未固定URL/未复制浏览器数据库明确标记 |
| 服务端插件/依赖 | 目标平台独立安装依赖、权限与设备路径；失败明确阻止或显示部分恢复 |
| 插件自身隔离 | 同步中的Helper及其配置/任务/SSH凭据不被镜像覆盖；更新代码等当前任务退出 |
| 设备字段 | JSON Pointer存在/缺失/null/类型异常与未知字段策略均正确；不使用文本替换 |
| 自定义dataRoot | 真正按当前启动参数绑定，错误实例/profile/祖先目录被拒绝 |
| 删除与空数据 | 删除只在stage对账；空/错误源、远端未初始化、异常大批删除不损坏当前数据 |
| 固定镜像与发布 | 上传中断/验证失败/current响应丢失均不暴露半代次；读pin不混批 |
| 跨设备锁 | 同时推/拉或控制断开而rsync仍在时，发布/GC/复用stage被阻止 |
| 块级增量 | 大JSONL局部改变只传差异；资源不变不传内容；统计区分逻辑大小和协议字节 |
| 同size/mtime内容变化 | 清单能检出且定向补传，不能靠rsync exit0误报完整 |
| 路径与类型安全 | 中文/空格、大小写冲突、Windows保留名、长路径、链接/junction、..与特殊文件逐项测试 |
| 故障恢复 | 每次rename/journal/指针替换前后注入崩溃；确认旧或新完整集可恢复，未确认退出不换文件 |
| 空间和文件锁 | VPS/手机/电脑低空间、Windows占用句柄均不变成原地覆盖或强杀 |
| SSH限制 | 错误密码/主机身份变化/非 Tailscale 来源/任意命令或越界模块拒绝；873端口未暴露 |
| 安全日志 | 不泄露模拟秘密；session/admin/CSRF和任务过期确认均做负向测试 |
