# 混合传输协议

客户端与 VPS 必须在 hello 中共同声明 `hybrid-v2`；新旧端不兼容，需同时更新。连接和能力检查发生在制作快照、传输和停止酒馆之前。升级前请等待当前传输完成。升级后的 VPS 会拒绝续传旧协议任务，保留其任务数据；需使用新协议重新发起任务。若必须续传旧任务，应保留原数据并在对应旧版客户端和 VPS 环境中处理，不能使用新协议重建旧计划。

变更文件中不超过 3 MiB 的文件按照路径确定性分组；每包原始文件总计不超过 16 MiB，最多 2000 个文件。更大的文件保留原路径，通过 rsync 块差分传输。计划绑定任务、数据集、原代次、范围与完整清单；恢复使用同一固定计划。

包由魔术字 `TSHYB001`、四字节大端无符号 JSON 头长度、规范 JSON 文件清单和连续原始字节组成，头部最多 1 MiB。头部包含计划摘要、序号、路径、大小、SHA-256 和时间戳；包另有 SHA-256。执行位仍由 `environment.executables` 恢复。

包创建、收发或合入中断后，可继续同一计划；rsync 保留可用断点，重连时重新握手和核对任务。接收方先验证包和成员，再写入独立暂存区；最终完整清单通过 SHA-256 校验后一次提交。分类同步按选中范围镜像删除，范围外保持不变。后端自动更新不会更新前端。

定向验证：Node 69/69 通过；Python 34 项通过、6 项因平台跳过。未验证实体 Android、线上 VPS 或完整 Node 测试套件；详见[验证记录](test-results/hybrid-transfer-windows.json)。
