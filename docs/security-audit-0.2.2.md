# 0.2.2 发布检查

日期：2026-10-25。

本次增加 Windows / Termux 启动更新、独立启动入口和 Termux 管理工具安装集成。发布文件与完整可达历史使用已有 Gitleaks 8.30.1 默认规则扫描；原始扫描记录留在忽略的 `.local/security/`，公开报告不包含设备路径、任务编号、密码或用户内容。

自动更新只查询配置在程序中的官方仓库稳定标签，不提供从网页或同步镜像指定执行来源的入口。版本检查与下载有时限，标签对象、包名和前后端版本需一致。仅在所属进程退出、端口空闲且没有待处理同步任务时替换代码；本机代码指纹改变时跳过自动更新。用户数据、设备配置及凭据文件不参与代码替换。

回归覆盖实际 Git 标签、后续手动快进更新、Windows 批处理、Bash 管理工具选项 4、离线时原版本启动、替换中断恢复、代码修改保护，以及既有服务的私有 epoch 校验。请求排空只豁免核验过的固定只读路由及 JSON 心跳；原始请求路径、编码遍历和全局 multipart 上传中间件均有回归，未知请求中断仍阻止自动停机。真实酒馆回归包括静态大文件下载中断后继续完成推送，以及未知插件中断拒绝停机。Windows 实际安装后核对前后端 0.2.2、完整启动入口、代码指纹及配置/设置/密码文件保持不变。Android 手机本次未连接，安装集成的真机复测仍待完成。[验证记录](test-results/startup-update-windows.json)。

其余历史范围见 [0.2.1 检查记录](security-audit-0.2.1.md)。

上传后的断线恢复固定原连接目标与数据集，并要求 VPS 以 `resumeOnly` 找回同一任务、代次和发布基准；不会因重连创建新任务或接受另一个数据集。发布回执仍需与原清单摘要一致。重连次数有限，VPS 暂存锁只等待有限时间，不删除锁、不强制接管。真实 SSH 回归验证断连后只执行一轮 rsync，以及丢失发布回执和数据集改变时的行为。
